# Aadi category illustrations

These nine original SVG illustrations are reused unchanged from the owner's Aadi rental explorer prototype (https://aadi-rental-explorer.information-7908.chatgpt.site/, retained source commit `a1c1127`). They depict example spaces, utility vehicles, and service workspaces.

The homepage uses them as editorial artwork. The listing image component uses them only when a real photo is absent or fails to load and displays an “Illustration” caption. They are not photos of real listings. No fictional listing records are added to the database.
